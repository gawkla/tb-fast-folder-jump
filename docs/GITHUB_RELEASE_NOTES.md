# Fast Folder Jump v0.1.5

**A fast, keyboard-first Thunderbird Local Folders navigator.**

Highlights:
- Shift+M Move, Shift+C Copy, Shift+G Jump to folder.
- Cached folder index and an in-window search panel to minimize opening latency.
- Exclude folders with the red minus or exclude entire branches in Settings.
- Append `!` to include excluded folders temporarily (`archive!`).
- Recently used folder priority; visible result count 4–30.
- Optional Ko-fi link in Settings.

**Supported manifest range:** Thunderbird 140.0–153.*. Experiment API permission is required. Local Folders only; do not assume IMAP support. Test message filing with disposable messages first.

**Install:** Download the attached `fast-folder-jump-v0.1.5.xpi` and install from Thunderbird's Add-ons and Themes screen.

**Note for users of the local test build:** the GitHub publishing ID is different (`gawkla.fast-folder-jump@addons.thunderbird.net`), so its local settings are separate.
