# Fast Folder Jump — Privacy Policy

Fast Folder Jump is a locally operating Thunderbird extension.

### Information processed
To provide folder search and message filing, it reads the Local Folders account structure, folder names, folder paths, locally assigned folder identifiers and the IDs of selected messages. It can move or copy messages only when the user chooses an operation. It does not analyze email message bodies to make recommendations.

### Local storage
The extension stores a cached catalog of Local Folders (including folder paths), folder exclusions, recent destinations, the last used folder and user preferences in Thunderbird extension local storage on the user's device.

### No telemetry or data transfer
Fast Folder Jump does not include analytics, trackers, advertising SDKs, remote APIs or background network requests. It does not transmit message contents, folder paths, identifiers or preferences to the developer or external servers.

### Donations
Settings contain an optional link to `https://ko-fi.com/gawkla`. No external Ko-fi content is loaded automatically. If the user clicks the link, they leave the extension and the destination website is subject to its own privacy policy. Donations are not required for any add-on functionality.

### User control
Exclusions and preferences can be changed in Settings. The extension's local stored data may be removed using Thunderbird's add-on and profile-management controls. Removing the add-on does not delete email messages.

### Scope and permissions
Fast Folder Jump searches folders only within Thunderbird's Local Folders account(s), and requests Thunderbird access required for the Move/Copy/Jump workflow. The included Experiment API allows fast keyboard integration and may cause Thunderbird to request full, unrestricted access to Thunderbird and the computer.
