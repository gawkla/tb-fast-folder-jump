Exclude folders from search

Keyboard shortcuts

Shift + M → Move selected messages; Shift + C → Copy; Shift + G → Jump to a folder.

↑ / ↓ → navigate results; Enter → confirm; Ctrl + Enter → move/copy then open destination; Esc → close.

Thunderbird already uses Shift+C for “Mark all as read”. When this extension is active in the message list, it intercepts that shortcut. Another extension (for example Nostalgy++) could also intercept these keys: disable conflicting shortcuts there.
